# StudyFlow — Python Study Tracker

StudyFlow is my first Python project, built to help students track their study sessions and stay motivated.

## Features
- Records the student's name, subject, study time, and difficulty level.
- Gives study suggestions based on the selected subject and difficulty.
- Evaluates whether a study session was productive.
- Checks progress toward a daily study goal.
- Allows students to start another session using a loop.
- Displays a summary of the study session.

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Download `studyflow.py`.
2. Open the file in VS Code.
3. Run the program using `python3 studyflow.py`.
4. Follow the questions in the terminal.

Building StudyFlow helped me practice Python variables, user input, conditional statements, lists, loops, and problem-solving.
